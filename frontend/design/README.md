# Design

Material de design do projeto, separado do código-fonte da aplicação
(`src/`) e do material de estudo sobre o código (`estudo/`).

## `styleguide.md`

Guia de estilo (cores, tipografia, espaçamento, componentes, voz e persona)
extraído da identidade visual já usada em `src/styles.css`, criado para
orientar o desenvolvimento futuro da **landing page** do Sistema de
Contagem de Alunos.

- **Ver o documento**: [`styleguide.md`](./styleguide.md)
- **Ver versão navegável** (cores e componentes renderizados de verdade):
  https://claude.ai/code/artifact/ce233530-c06e-44b2-8997-b29697f84300

### Persona usada como base

**Márcia Souza**, coordenadora pedagógica: faz chamada em sala de aula,
em passeios escolares e na saída para o ônibus — geralmente de pé, com
uma mão só livre. O medo que a landing page precisa desarmar é perder o
progresso da contagem no meio do processo.
